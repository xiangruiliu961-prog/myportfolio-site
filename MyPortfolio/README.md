## 一、项目概述 / 프로젝트 개요

本项目是一个专为大学生设计的完整、现代、高颜值的个人作品展示网站（Personal Portfolio Website）。整体采用**现代简约蓝白科技风格（Modern Blue & White Minimalist Design）**，排版精致美观，信息层级分明，深度适配桌面电脑、平板与智能手机等各种设备屏幕。

### 🌟 核心特色 / 핵심 하이라이트
1. **中韩双语并排对照呈现（Bilingual Display）**：
   - 全站所有用户可见的标题、副标题、正文、按钮、标签、弹窗内容及操作反馈均**严格采用中文与韩文并排并列呈现**（例如：`首页 / 홈`、`关于我 / 자기소개`、`我的作品 / 나의 작품`、`联系方式 / 연락처`）。
2. **纯原生现代 Web 技术栈（Pure Native Web Stack）**：
   - 基于语义化 **HTML5**、现代 **CSS3（Flexbox & Grid）** 与原生 **JavaScript (ES6+)** 构建，不依赖繁重的第三方臃肿框架，轻量级、零网络 CDN 依赖、秒级启动。
3. **沉浸式即时交互与实时演示（Interactive Live Demos）**：
   - 包含可实际试玩的 **HTML5 Canvas 动作游戏**（飞船漫游 / 像素地牢闯关）。
   - 包含可实时调参的 **Python 数据分析与可视化流水线仿真器**。
   - 包含可即时体验的 **BERT 双语自然语言情感分析推理测试器**。
4. **全功能闭环（Zero Dead Buttons）**：
   - 绝无任何空白页面或无法点击的死按钮。所有按钮均绑定真实业务逻辑（作品详情弹窗、交互演示运行、一键复制邮箱、在线简历预览/打印 PDF、表单即时格式验证、动态浮动 Toast 通知等）。

## 五、运行步骤与使用方法 / 실행 및 사용 방법

本网站采用标准的前端原生技术，**不需要**编译打包工具（如 Webpack/Vite），**不需要**配置复杂的后端环境。

### 方法一：直接双击打开（最简单）
1. 打开项目根文件夹 `MyPortfolio`；
2. 找到 `index.html` 文件；
3. 直接双击该文件，或右键选择任意现代浏览器（Google Chrome、Microsoft Edge、Safari、Firefox）即可直接流畅浏览。

### 方法二：使用 Python 本地 HTTP 服务运行（推荐）
在终端或 PowerShell 中进入项目目录并执行：
```bash
# 进入项目目录
cd c:\Users\Administrator\Desktop\MyPortfolio

# 启动本地轻量 HTTP 服务器（端口例如 8080）
python -m http.server 8080
```
启动后在浏览器地址栏输入：
```text
http://localhost:8080
```
即可获得最佳的本地 Web 预览体验。

### 方法三：使用 VS Code Live Server 插件
1. 使用 Visual Studio Code 打开 `MyPortfolio` 文件夹；
2. 安装扩展插件 `Live Server`；
3. 打开 `index.html`，右键点击选择 **"Open with Live Server"** 即可。

## 六、交互功能测试清单 / 인터랙티브 기능 검증 가이드

在浏览器中运行网站时，您可以逐项检验以下功能：

1. **导航菜单切换：**
   - 点击导航栏各菜单项，页面平滑滚动至对应章节，导航菜单高亮对应位置。
   - 缩小浏览器窗口至手机尺寸，右上角出现汉堡按钮，点击可弹出/收起移动端折叠菜单。
2. **技能筛选功能：**
   - 在“我的技能”区域点击 `编程语言`、`游戏引擎`、`Web 前端`、`机器学习与工具` 按钮，卡片动态筛选对应技能。
3. **作品卡片分类与详情：**
   - 在“我的作品”区域点击分类标签切换作品集合；
   - 点击任意卡片上的 **【查看详情 / 상세정보】**，弹出包含项目架构、特色亮点及技术芯片的弹窗；
   - 点击卡片上的 **【运行演示 / 데모 실행】**，即刻体验内嵌交互组件（Canvas 动作游戏、数据分析图表模拟器或 BERT 文本情绪分析）。
4. **个人简历预览与打印：**
   - 点击导航栏或首页上的 **【个人简历 / 이력서 확인】** 按钮，弹出完整的中韩双语学业与求职简历，支持点击 **【打印 / 保存为 PDF】** 调出浏览器原生打印保存界面。
5. **联系方式与在线留言：**
   - 点击 **【复制邮箱 / 복사】** 按钮，触发剪贴板复制并弹出成功 Toast 浮动提示；
   - 提交留言表单测试：未填写时提交会提示红色校验错误；完整输入后点击发送，展示加载状态并提示成功 Toast 发送成功。
6. **回到顶部：**
   - 页面向下滚动超过 400px 时，右下角优雅浮现回到顶部按钮，点击平滑回滚至页面最上方。
